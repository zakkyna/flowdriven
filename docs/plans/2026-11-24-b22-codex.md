# B-22 Codex (V1 build plan step)

Copied from `docs/design/build-order.md` section B-22; that file and the design set it names are the instructions. Approval basis: the owner approved the clickable prototype ("sudah oke", 2026-11-21) and asked for the whole V1 build to start, test first, with no questions before V1 is done.


- Release: V1.
- Goal: Codex runs chat turns and flow steps behind the same port, always in its workspace-write sandbox. When the chat's agent cannot be limited for a flow, FlowDriven says so and starts nothing (PU-26). A research step first reads Codex's local help and version output.

- Ask first: None.
- Dependency changes: none.
- Security review: Required (sandbox limits). Focus: T-12, T-18, T-19. Why: the Codex sandbox.
