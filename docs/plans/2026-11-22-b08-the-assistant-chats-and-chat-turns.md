# B-08 The assistant: chats and chat turns (V1 build plan step)

Copied from `docs/design/build-order.md` section B-08; that file and the design set it names are the instructions. Approval basis: the owner approved the clickable prototype ("sudah oke", 2026-11-21) and asked for the whole V1 build to start, test first, with no questions before V1 is done.


- Release: V1.
- Goal: A chat message is stored at once and answered by one agent call with no tools; FlowDriven validates the answer and turns it into messages and cards; nothing starts that was not asked.
